# Nexpense UI Overview

Nexpense uses a quiet, receipt-inspired visual style designed for quick daily use. The interface supports light, dark, and system appearance choices.

## Main areas

- **Record:** enter an expense, review the parsed amount and category, and edit or delete saved entries.
- **Receipt:** browse an itemized day and share a receipt image.
- **Insight:** review totals by day, month, and year with category breakdowns.
- **Settings:** manage categories, currency, language, appearance, import/export, and local data controls.

On wider screens, the record and secondary content use an adaptive two-pane layout. The screen components use the shared Compose design system in the app module.

User-facing text is stored in Android string resources. Screens and dialogs use Compose semantics so controls can be reached and understood with accessibility services.

This file is an overview of Nexpense's own interface. It contains no local machine paths or external app assets.
