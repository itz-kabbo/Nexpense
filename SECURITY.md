# Security policy

Nexpense stores personal expense records, so please handle potential security issues carefully.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue. Use GitHub’s **Report a vulnerability** option in the repository’s Security tab to send a private report. If private vulnerability reporting is unavailable, contact the repository owner through the GitHub profile and ask for a private reporting route.

Include the affected version or commit, the impact, and concise reproduction steps. Do not attach real financial records, signing keys, passwords, or other private data.

## Supported versions

Security fixes are evaluated for the latest source on the default branch and the latest published release.
