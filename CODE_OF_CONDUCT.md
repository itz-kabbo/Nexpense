# Code of Conduct

Nexpense aims to be a respectful, welcoming project for people with different backgrounds and experience levels.

## Expected behavior

- Be considerate, constructive, and respectful in issues, reviews, and discussions.
- Explain disagreements without personal attacks or harassment.
- Respect privacy. Do not post anyone’s personal information, real expense records, passwords, signing credentials, or private vulnerability details.
- Keep feedback relevant to the project and its users.

## Unacceptable behavior

Harassment, discrimination, threats, intimidation, personal attacks, doxxing, and deliberately publishing private data are not acceptable in project spaces.

## Reporting and enforcement

Report conduct concerns privately to the repository owner through the owner’s GitHub profile. Project maintainers may edit or remove content and restrict participation when needed to protect contributors and users.

This policy applies to project issues, pull requests, discussions, and other spaces used to represent Nexpense.
